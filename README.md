# 📊 Social Media Analytics Project (Excel)

## 🧭 Overview
This project focuses on analyzing social media data using Microsoft Excel to evaluate performance across platforms, content types, campaigns, and hashtags. The objective is to derive actionable insights that help improve engagement and optimize marketing strategies.

---

## 📁 Dataset
The dataset includes:
- Platform (Instagram, YouTube, LinkedIn, etc.)
- Date
- Content Type (Video, Image, Tweet)
- Likes, Shares, Comments
- Clicks
- Reach and Impressions
- Campaign Name
- Hashtags

---

## 🎯 Objectives
- Analyze engagement across different platforms  
- Identify top-performing content types  
- Measure campaign effectiveness  
- Evaluate hashtag performance  
- Track engagement trends over time  

---

## 🧮 Key Metrics

- **Engagement Score** = Likes + Shares + Comments  
- **Engagement Rate** = (Likes + Shares + Comments) / Impressions  
- **Click-Through Rate (CTR)** = Clicks / Impressions  
- **Campaign Uplift** = (During Campaign - Before Campaign) / Before Campaign  

---

## ⚙️ Tools Used
- Microsoft Excel  
- Pivot Tables  
- Charts (Line, Bar)  
- Conditional Formatting  
- Basic Formulas  

---

## 📊 Analysis Performed

### Platform Analysis
Compared engagement metrics across platforms to identify which platform performs best.

### Content Type Analysis
Evaluated performance of videos, images, and text-based posts to determine the most effective format.

### Hashtag Analysis
Measured average engagement per hashtag to identify high-performing tags.

### Campaign Analysis
Compared engagement before and during campaigns to measure impact and uplift.

### Trend Analysis
Analyzed weekly or monthly trends to identify growth patterns and engagement spikes.

---

## 📈 Insights
- Certain platforms drive higher engagement than others  
- Videos often generate more interaction compared to static posts  
- Campaign periods show noticeable spikes in engagement  
- Some hashtags consistently outperform others  

---

## 🚀 Conclusion
This project demonstrates how Excel can be used to perform effective social media analytics. By leveraging pivot tables, formulas, and visualizations, meaningful insights can be derived to support data-driven decision-making.
